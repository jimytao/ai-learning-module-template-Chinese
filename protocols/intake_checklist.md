# Phase 0 采集确认清单 (intake_checklist.md)

> **给 AI 用的强制访谈单。** Phase 0 开始时必须加载本文件。  
> 目标：在生成任何科目内容之前，把学习者与学习方式问清楚，并让用户**逐项确认**。  
> 禁止凭猜测填满画像。

---

## 使用方式

1. AI 按下方 **A→G** 向用户提问（可合并成一次提问，但槽位不得省略）。  
2. 用户回答后，AI 填写「确认卡」回显，请用户说「确认」或指出修改。  
3. **仅在用户确认后**，才写入 `profile.md` / `desire.md` / `gaps.md` / `domain_map.md` / `calendar.md`，并执行 `AGENT.md` 的「Bootstrap 后改造」。  
4. 未确认前：可以讨论、给建议，但**禁止**生成 Magazine/Unit 正文。

## H. 内容形态偏好（配图 / 图示 / 便利贴 / 题型）

> **必问。** 这一组决定 Phase 2 每次生成出来长什么样。不问就只能靠猜，教案会千篇一律。
> 图示语法见 `protocols/visual_arsenal.md`，题型语法见 `protocols/tech_spec.md`；这里只问偏好，不解释语法。

### H1 配图密度

| 选项 | 含义 |
| :--- | :--- |
| `none` | 完全不配图（纯文字 + 表格；网络受限或不想下载图片时选） |
| `light` | 每篇 1–2 张（模板默认） |
| `medium` | 每个大节 1 张 |
| `rich` | 概念词条尽量都配图 |

用户选择：______

### H2 图示武器偏好

问：「解释过程、结构、层级的时候，你希望多用图，还是多用文字和表格？」

| 档位 | 含义 |
| :--- | :--- |
| `minimal` | 只用 `table` + `steps`，不画图 |
| `standard` | 每篇至少 1 处流程 / 树 / 框图（模板默认） |
| `heavy` | 能图则图，概念之间的关系尽量画出来 |

可让用户从 `visual_arsenal.md` §1 的 Type 里勾常用项（也可以答「AI 自行判断」）：
`table` / `steps` / `callout` / `flow` / `tree` / `seq` / `state` / `blocks` / `svg-lite` / `formula`

用户选择：档位 ______ ｜偏好 Type ______ ｜想避开的 Type ______

### H3 便利贴 / 旁注（sticky-note）

问：「要不要在正文旁边放便利贴一样的小块——补充冷知识、易错提醒、延伸阅读？」

| 选项 | 含义 |
| :--- | :--- |
| `off` | 不要 |
| `light` | 每篇 1–2 张（模板默认） |
| `rich` | 每个大节 1 张 |

想要哪几类（可多选）：`延伸知识` / `易错点` / `冷知识·趣闻` / `数据与文献` / `助记` / `真实应用场景`

用户选择：档位 ______ ｜类型 ______

### H4 题型偏好（必问）

模板已支持的全部题型 —— 语法见 `tech_spec.md`：

| 题型 | 标记 | 规范 |
| :--- | :--- | :--- |
| 填空 | `___` / `__已填__` | tech_spec §1 |
| 开放问答 | `**[Your Answer]**` | tech_spec §2 |
| 单选题 MCQ | `- [ ]` + `<!-- answer: B \| … -->` | tech_spec §3 |
| 多选题 MSQ | `- [ ]` + `<!-- answers: A,C \| … -->` | tech_spec §3.5 |
| 判断题 T/F | `- [ ] True / False` | tech_spec §4 |

问用户：**喜欢哪几类？想避开哪几类？每个 Unit 大概想做多少题？**（例如「不喜欢开放问答，想多做选择题」）

用户选择：常用 ______ ｜避开 ______ ｜每 Unit 题量 ______

> **底线**：用户勾掉的题型，Phase 2 的最低数量随之作废（见 `p2_generate.md` §0.5）；但**至少要保留两类**，
> 否则只剩再认层，无法评估应用能力（黄金规则 6）。若用户的取舍只剩一类，说明原因并请其再选一类。

### H5 版面口味（可选）

- 每篇是否要「本期速览」开头 +「三句话总结」结尾：是 / 否
