| 状态 | 含义 |
| :--- | :--- |

## 详细备注

### G01 — Logical & Critical Thinking in Argumentation
- 首次登记：Phase 0 (2026-08-25)
- 相关 domain 节点：2.1, 2.2
- 核心考查：能否在段落中明确区分 Claim（主张）、Evidence（证据）、Warrant（推导逻辑）并提出有力的 Counter-argument。

### G02 — Theme and Rheme Progression
- 首次登记：Phase 0 (2026-08-25)
- 相关 domain 节点：3.1
- 核心考查：能否熟练运用 Constant Theme（延续主位）、Linear Theme（线性主位）推进信息，避免段落思维跳跃。

### G03 — Cohesion & Coherence
- 首次登记：Phase 0 (2026-08-25)
- 相关 domain 节点：3.2
- 核心考查：段落间的逻辑链条与语篇呼应，自然过渡而非生硬插词。

### G04 — Idea Generation & Thesis Formulation
- 首次登记：Phase 0 (2026-08-25)
- 相关 domain 节点：1.1, 1.2
- 核心考查：提出清晰、具体、具有可辩论性 (Arguable) 的 Thesis Statement。

### G05 — Grammatical Accuracy & Sentence Architecture
- 首次登记：Phase 0 (2026-08-25)
- 相关 domain 节点：4.1
- 核心考查：消灭学术写作中致命的结构性语法错误，写出严谨合规的复合句。
